
# Kalman Filter for Financial Time Series 
This project applies a Kalman Filter to noisy stock-price data in order to estimate the underlying trend.
Features:
1 Synthetic Gaussian noise simulation
2 Kalman filtering using a constant-velocity state-space model
3 Q/R sensitivity analysis
4 Innovation sequence analysis
5 Comparison against moving averages

Tools Used:
1 NumPy
2 Pandas
3 Matplotlib
4 FilterPy
5 yfinance
